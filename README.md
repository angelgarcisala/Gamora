# Gamora

**Gamora** is a desktop-oriented game library and launcher built with Laravel, Livewire, and Tailwind CSS.  
Inspired by platforms like Steam, Gamora enables users to browse, purchase, organize, and launch PC games from a single unified interface.

Designed as a full-stack solution, Gamora includes both a responsive web interface and a native desktop client (Electron-based) to handle local game execution and management.

---

## 🎮 Key Features

- Full user authentication and profile system
- Public and private game library management
- In-browser game presentation with cover art, trailers, and metadata
- Game upload system with drag & drop support
- Virtual currency balance and wallet system
- Game purchasing with balance deduction and ownership logic
- Local executable configuration for desktop launching
- Admin panel with full game and user management
- Favorites (wishlist), likes, and comment system for community interaction
- Responsive and animated UI with Tailwind + Alpine.js + Livewire

---

## 🧱 Tech Stack

**Backend:**
- Laravel 10
- Livewire 3
- PHP 8+

**Frontend:**
- Blade components
- Tailwind CSS
- Alpine.js

**Storage:**
- AWS S3 for file and image uploads

**Desktop Integration:**
- Compatible with Gamora Desktop (Electron-based launcher for local game execution)
